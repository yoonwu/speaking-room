대상: 기존 Android 0.6.2 / code 17의 별도 학습 화면. 네이티브·마이크·음성 서버 변경은 없으며 새 AAB 없이 적용한다. minimumNativeVersion 17을 유지한다.

**배포 완료:** 소스 `789a4c675df269659c9ce42ff101a780b01a6f6c`, [Actions 42362589165](https://github.com/yoonwu/speaking-room/actions/runs/42362589165) 성공. 실제 `android-web-live` descriptor가 이 소스를 가리키며, 새 `practice-session.js`를 포함한 17개 파일의 크기·SHA-256·고정 소스 바이트 일치를 확인했다. 앱 홈의 업데이트 확인으로 적용한다. 증거는 `outputs/web-v4.7.1-published.json`에 보관했다. Play 0.6.2 출시 12의 설치 파일을 다시 게시한 변경은 아니다.

## 달라진 동작

- 시작할 때 정한 문항 수를 유지한다. 오답·힌트·재도전 뒤에 문항을 자동으로 삽입하던 동작을 제거했다. 같은 자리에서 다시 말해 맞히면 다음 버튼으로 이어지고, 마지막 문제 다음은 즉시 완료된다. 종료 화면의 어려운 문장 재연습은 사용자가 선택하는 별도 연습이다.
- 최초 정답/표현 점수 30/15/15/10 XP를 유지하고, 이후 완전한 정답에 한 번 5 XP를 준다. 최초 오답 뒤 표현만 맞힌 재도전에도 기존 5 XP를 유지하며, 이후 완전 정답과 같은 5 XP 한도를 공유한다. 중복 콜백·복제 문항·기록 병합으로 보너스를 중복 지급하지 않는다. 과거 v2 보상은 보존한다.
- 완료 화면에 실제 XP와 레벨, 바로 꺼낸 표현, 재도전으로 완성한 문장, 최종적으로 더 연습할 문장을 표시한다. 재도전 답변 수와 최초 문항 수를 구분한다.
- 연습 전후의 표현 점수와 문장 익숙함을 비교한다. 이전에 실제 연습한 기록이 있는 문장만 '지난번보다 늘었어요'에 넣고, 새 표현 점수는 '새로 쌓은 기록'으로 구분한다. 최초 소개·힌트·직접 입력·재도전을 빠른 독립 회상으로 표시하지 않는다.
- 통계는 정규화한 고유 문장으로 묶고, 동일 attemptId의 XP를 중복 합산하지 않는다. 음성 녹음이나 ChatGPT 연결 정보는 결과 통계에 보관하지 않는다. 프로필 기록 격리와 기존 저장·동기화 방식을 유지한다.
