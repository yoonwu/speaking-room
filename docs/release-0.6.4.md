# 3초영어 0.6.4 / v4.7.3 음성 대기 개선

Android **0.6.4 / 코드 19**, 학습 화면 **v4.7.3 / 최소 앱 코드 19**. 기존 설치 기록과 음성 인식 원문 처리 정책은 유지한다.

- 확인 당시 Play 내부 테스트는 0.6.3(출시 13), 라이브 학습 화면은 v4.7.2, 음성 서버는 worker-v11이었다. 배포 롤백은 확인되지 않았다.
- 이전 Android 기본 음성 인식은 녹음 종료 후 실시간 SDK를 최대 7초 기다린 다음, 실패 시 같은 WAV로 REST를 최대 7초 더 기다릴 수 있었다. 이제 종료 이후 **6초**를 두 단계가 공유한다. 연결이 준비된 SDK는 2.6초, 아직 연결 중인 SDK는 4초를 부여한다. 별도 REST 스트림의 자체 종료 대기는 5.5초다. REST 재시도는 같은 녹음을 이용하며, 시간 초과는 채점하지 않는다. 일시 실패로 실시간 경로를 피하는 시간은 5분에서 12초로 줄였다.
- Android 녹음 종료는 조용해진 뒤 단어 증거 없음 1.2초, 들은 단어가 기준보다 적음 1.6초, 기준 충족 0.65초를 적용한다. 이전 1.4초 / 2.2초 / 0.65초였다. 문장 중간에 잠깐 멈췄다가 이어 말할 수 있도록 발화 시작이나 첫말 대기는 변경하지 않았다.
- 브라우저의 기본 인식에도 같은 6초 한도를 적용한다. 장치 인식 결과가 늦으면 기존 Azure 경로를 한 번 사용한다. 종료 직전 250ms 사이에 다시 말하면 예정된 녹음 종료를 취소한다.

확인 범위: Node 모의 브리지·브라우저 테스트 **233/233** 통과. 6초를 SDK와 REST가 공유하는 경우, 두 번째 서버 요청 없음, 타임아웃 후 늦은 결과를 채점하지 않는 경우를 포함한다. 합성 음성을 보낸 Azure 운영 REST 응답은 약 2.3초, 2.9초, 4.8초였다. 데스크톱 SDK와 합성 음성 결과는 실제 휴대폰 실측과 구분한다.
