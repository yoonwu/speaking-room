# 3초영어

상황을 보고 바로 영어를 말하는 반복학습 앱입니다. 메뉴는 네 가지입니다.

- 기본표현: 처음에는 표현을 보여주고 이후에는 상황만 보고 말합니다. 틀린 문장은 뒤에 다시 나옵니다.
- 골라서 연습: 필요한 기본표현을 선택해 해당 표현만 반복합니다.
- 자주 틀리는 문장: 오답을 모아 반복하며 연속 3번 맞히면 목록에서 빠집니다.
- AI 실전회화: 상황을 고르면 짧은 영어 대화를 시작합니다. 막혔을 때 도움말과 내 표현 확인을 사용할 수 있습니다.

기존 기본표현·선택·오답의 localStorage 키를 유지합니다. 오늘의 루틴·퀘스트, 성장 기록, 자동 난이도, 랭킹, 프로필, 닉네임 동기화, 시작 안내는 기존 민트색 UI를 바탕으로 복원했습니다. 오늘의 루틴은 기본표현 10회 하나이며, 기본표현을 홈 최상단의 큰 카드로 강조합니다. 골라서 연습·자주 틀리는 문장·AI 실전회화는 보조 메뉴입니다. XP/게임 보상, 단어·파닉스·별도 듣기·스피드런·별도 블록 훈련은 제거한 상태입니다. 기존 저장 데이터를 일괄 삭제하지 않습니다.

`index.html`, `practice.css`, `practice.js`, `practice-data.js`가 현재 웹 앱입니다. `practice-data.js`는 기존 여행 자료/선택/판정/음성 입력·읽기 공통 도구만 보관합니다. `home-support.js`는 홈, 프로필, 성장, 자동 난이도, 루틴, 랭킹, 동기화, 튜토리얼입니다. `android-native.js`는 Android의 ChatGPT 연결과 AI 회화 음성을 같은 화면에 붙입니다.
