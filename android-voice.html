기존 3초영어에
구독·음성 대화 연결

기존 학습 화면에서 상황을 선택하고, 음성으로 같은 대화를 이어갑니다. 음성 답변도 기존 학습 기록에 반영됩니다.

안드로이드 통합판 다운로드

Android 8 이상 · 0.2 개인 시험용 APK. 이전 시험 앱을 삭제하지 말고 위에 업데이트하세요.

설정과 시작

  1. 앱의 구독·음성 → ChatGPT 구독 설정에서 로그인하고 모델을 불러온 뒤 연결 테스트를 완료합니다.
  2. 기존 스피킹 훈련장 → 실전회화에서 상황을 선택하고 첫 질문을 받습니다.
  3. 구독·음성 → 현재 대화에서 음성 시작을 누르고 마이크·알림 권한을 허용합니다.

상대가 말을 마친 뒤 영어로 답하세요. 듣는 동안 Repeat / Help / Stop을 사용할 수 있습니다. 지난 대화 반복은 AI 요청과 자동 채점 없이 질문을 다시 연습합니다.

기존 학습 기록

기존 웹에서 사용한 같은 동기화 닉네임으로 앱에서도 연결하세요. 브라우저와 앱의 저장 공간이 달라 로컬 기록은 자동으로 이동하지 않습니다. 기록 파일 저장·가져오기도 지원합니다.

사용량과 확인 범위

AI 요청은 승인된 ChatGPT 구독 한도를 사용합니다. 음성은 Android 인식과 읽어주기로 구현했습니다. 실제 계정 로그인, 화면 잠금과 차량 Bluetooth는 휴대폰에서 확인이 필요합니다. 설정·시작·복구는 정차 상태에서 진행하세요.
