학습 기록과 학습자 프로필

기본표현 연습, 선택한 표현, 자주 틀리는 문장, 점수와 문장별 숙련도 기록은 기기에 저장됩니다. 학습자 프로필을 추가하면 이름, 학습 기록, 문장별 숙련도, 발음 판정 설정을 프로필마다 따로 저장합니다. 프로필은 이 기기의 기록을 구분하는 기능이며 별도 로그인 계정은 아닙니다. 기존 기록은 ‘기존 학습자’에 유지됩니다.

사용자가 기록 동기화를 연결하면 표시 이름, 기본표현·선택·오답·성장·루틴 기록, 문장별 숙련도와 발음 판정 설정이 기존 Cloudflare 동기화 서버에 저장됩니다. 같은 동기화 닉네임으로 연결한 기록은 기기 간에 합쳐질 수 있으므로 서로 다른 학습자는 다른 닉네임을 사용해야 합니다. 표시 이름과 학습 시간·레벨·연속 학습 등 랭킹 요약은 공개되며, 문장별 숙련도 상세·발음 판정 설정·의미 판정 사용량 기록은 랭킹에 공개하지 않습니다. 닉네임만으로 연결하는 방식이므로 추측하기 어려운 별명을 사용해야 합니다. ChatGPT 로그인 토큰과 대화 내용은 동기화 대상이 아닙니다. 자동 동기화 끄기는 이후 자동 저장을 중단하며 기존 서버 기록을 삭제하지 않습니다. 이전 버전으로 서버에 저장했던 기록이 자동으로 삭제되지는 않습니다.

AI 대화

AI 실전회화를 실행하면 상황과 대화 텍스트가 AI 서비스에 전달됩니다. Android에서 ChatGPT를 연결하면 OpenAI로 전달되고 연결한 계정의 사용 권한·한도가 적용됩니다. 일반 웹에서는 기존 3초영어 Cloudflare 프록시와 Anthropic 서비스를 사용합니다.

음성 입력과 읽기

사용자가 마이크를 켜면 음성을 녹음하고 인식합니다. 기본값인 정확도 중심 모드의 Android 반복학습은 기기에서 녹음한 음성을 운영 프록시를 통해 Microsoft 음성 인식 서비스로 전송하며, 장애 시 OpenAI 음성 인식 서비스로 대체될 수 있습니다. 실시간 인식을 지원하는 앱에서는 같은 녹음의 소리를 Microsoft 서비스로 스트리밍합니다. 브라우저와 이전 앱 버전은 기기 음성 인식 또는 운영 프록시의 음성 인식을 사용합니다. 예문 음성 읽기는 운영 프록시·Microsoft 음성 서비스를 사용하고, 실패할 때 기기의 기본 읽기로 대체합니다. Android AI 음성 대화는 기기 음성 인식·읽기를 사용하며 음성 데이터가 기기의 음성 인식 제공업체로 전달될 수 있습니다. 반복학습의 음성 입력에는 ChatGPT 로그인이 필요하지 않습니다.

선택형 의미 중심 판정

설정에서 의미 중심 모드를 선택하면 녹음을 운영 Cloudflare 프록시를 거쳐 OpenAI 음성 인식 API로 전송합니다. 인식된 문장만으로 판단하기 어려운 경우 인식 문장과 목표 학습 문장을 OpenAI 텍스트 API로 보내 뜻과 핵심 낱말을 비교합니다. 목표 정답 문장을 음성 인식의 힌트로 보내지 않습니다. 이 기능은 운영자가 별도로 확인한 API 크레딧과 사용 한도가 준비된 경우에만 사용할 수 있으며, ChatGPT 계정 로그인과는 별도입니다. 정확도 중심 모드로 바꿔 기존 연습을 계속할 수 있습니다.

운영자의 KV 학습 저장소에 녹음 파일을 저장하지 않습니다. 중복 요청과 비용을 줄이기 위해 요청 ID, 입력·접속 IP의 해시, 처리 결과(인식 문장 포함)를 최대 10분 동안 일시 저장합니다. 속도 제한용 IP 해시 기록은 2분, 월별 호출 수와 보수적인 비용 예약 합계는 마지막 갱신 후 최대 40일 동안 저장합니다. 이는 실제 결제액이나 남은 API 크레딧 잔액을 뜻하지 않습니다. 외부 음성·AI 서비스의 처리와 보관에는 해당 제공자의 정책이 적용됩니다.

기기의 의미 판정 사용량 기록에는 요청 ID, 처리 시각, 기능·모델명, 호출 수, 처리 시간과 예상 비용을 최근 500건까지 프로필별로 저장합니다. 이 사용량 기록에 녹음이나 인식 문장 전체를 저장하지 않으며, 기기 간 동기화와 랭킹에도 보내지 않습니다. 학습 기록에는 목표 학습 문장과 정오답·점수·숙련도 등 결과가 저장됩니다.

내 목소리 듣기

답변의 녹음을 기기 메모리에서 일시적으로 유지해 예문과 비교할 수 있습니다. Android에서 별도로 녹음해 듣는 경우 그 녹음은 기기에서만 처리합니다. 다음 문장이나 홈으로 이동하면 재생용 녹음을 해제하고, 학습 기록·랭킹·동기화 서버에 녹음 파일을 저장하지 않습니다. 음성 인식에 필요한 전송은 위의 음성 입력과 의미 중심 판정 안내를 따릅니다.

계정 연결

비밀번호는 공식 로그인 화면에서 입력하며 3초영어가 받지 않습니다. 계정 식별 정보, 연결 권한, 토큰은 Android 앱 저장소에 암호화해 보관합니다. 연결 설정의 로그아웃 또는 연결 정보 삭제로 기기에서 지울 수 있습니다. 서버의 앱 권한은 ChatGPT 설정에서도 해제할 수 있습니다. 의미 중심 판정용 서버 API 키는 앱이나 브라우저 저장소로 전달하지 않습니다.
