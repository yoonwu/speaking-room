학습 기록

기본표현 연습, 선택한 표현, 자주 틀리는 문장 기록은 기기에 저장됩니다. 사용자가 기록 동기화를 연결하면 표시 이름, 기본표현·선택·오답·성장·루틴 기록이 기존 Cloudflare 동기화 서버에 저장됩니다. 같은 닉네임으로 기기 간 기록을 합칠 수 있습니다. 표시 이름과 학습 시간·표현 숙련도·연속 학습 통계는 랭킹에 공개됩니다. 닉네임만으로 연결하는 방식이므로 추측하기 어려운 별명을 사용해야 합니다. ChatGPT 로그인 토큰과 대화 내용은 동기화 대상이 아닙니다. 자동 동기화 끄기는 이후 자동 저장을 중단하며 기존 서버 기록을 삭제하지 않습니다. 이전 버전으로 서버에 저장했던 기록이 자동으로 삭제되지는 않습니다.

AI 대화

AI 실전회화를 실행하면 상황과 대화 텍스트가 AI 서비스에 전달됩니다. Android에서 ChatGPT를 연결하면 OpenAI로 전달되고 연결한 계정의 사용 권한·한도가 적용됩니다. 일반 웹에서는 기존 3초영어 Cloudflare 프록시와 Anthropic 서비스를 사용합니다.

음성 입력과 읽기

사용자가 마이크를 실행하면 음성을 인식합니다. 웹의 기기 음성 인식 또는 기존 프록시·Microsoft 음성 서비스를 사용할 수 있으며 인식 서비스에 따라 음성이 서버로 전달됩니다. 웹의 영어 읽기는 기존 프록시·Microsoft 음성 서비스를 사용하고 사용할 수 없으면 기기 읽기로 대체합니다. Android AI 음성 대화는 기기 음성 인식·읽기를 사용하며 기기와 설정에 따라 음성 인식 제공업체로 전달될 수 있습니다. 발음 점수 기능은 제거했습니다.

계정 연결

비밀번호는 공식 로그인 화면에서 입력하며 3초영어가 받지 않습니다. 계정 식별 정보, 연결 권한, 토큰은 Android 앱 저장소에 암호화해 보관합니다. 연결 설정의 로그아웃 또는 연결 정보 삭제로 기기에서 지울 수 있습니다. 서버의 앱 권한은 ChatGPT 설정에서도 해제할 수 있습니다.

학습 화면 업데이트

Android 앱은 개발자의 GitHub 저장소에서 학습 화면과 자료를 내려받습니다. 이 과정에서 학습 기록이나 ChatGPT 연결 토큰을 GitHub로 보내지 않습니다.

마이크는 음성 연습에 사용하고 Android 알림은 진행 중인 AI 음성 대화와 멈추기 버튼에 사용합니다. 앱 삭제 또는 앱 저장공간 초기화는 기기의 기록과 연결 정보를 삭제합니다. 동기화 서버의 기록은 서비스 제공 중 보관하며 삭제 요청 시 삭제합니다. 서버 기록 삭제는 thdghkstlr@gmail.com으로 사용한 동기화 닉네임과 삭제 요청을 보내주세요. 요청 확인을 위해 추가 정보를 요청할 수 있습니다. 비밀번호나 ChatGPT 토큰은 보내지 마세요. 삭제 시 랭킹 요약과 보관된 이전 기록도 삭제 대상입니다. 앱 삭제만으로 서버 기록이 삭제되지는 않습니다.
