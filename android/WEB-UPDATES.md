Android 0.6.3/code 18의 음성 인식 원문 선택 수정과 함께 적용하며, 2026-11-07 19:32 KST에 Play 내부 테스트 출시 13의 테스터 제공 상태를 확인했습니다. 0.6.2/code 17은 호환되는 기존 화면을 유지합니다. [0.6.3 검증 기록](../docs/release-0.6.3.md)을 참고하세요.

**이전 별도 학습 화면 v4.7.1 배포 완료:** Android 0.6.2/code 17에서 홈의 업데이트 확인으로 적용한다. 연습 분량 고정, 재도전 정답 보너스 5 XP, 잘한/어려운/나아진 문장 완료 통계를 추가했다. Node 221/221, 실제 브라우저 UI 및 390px 배치, 배포 파일 17개의 일치를 확인했다. 네이티브·음성 서버 수정이나 새 AAB 게시가 아니다. [v4.7.1 검증 기록](../docs/web-v4.7.1.md)을 참고한다.

이전 내부 테스트는 **0.6.2/code 17 · v4.7.0 · 출시 12**입니다. **2026-11-07 18:46 KST에 내부 테스터 제공 상태를 확인**했습니다. 서버 연결과 휴대폰 녹음을 병행하고, 기존 표현 10개부터 표현 익숙함 8/10 기준으로 다음 표현을 엽니다. 시간 기준은 **3초 안에 누르기 + 녹음 준비 뒤 1.5초 안에 말 시작하기**이며 단어 완성과 표현 익숙함을 구분합니다. Node 201개·JVM 70개·서명·포함 자산과 웹 배포를 확인했습니다. 실제 휴대폰 실측은 미확인입니다. [0.6.2 검증·게시 기록](../docs/release-0.6.2.md)을 참고하세요. 아래 0.6.1 내용은 이전 출시 이력입니다.

0.4.0 (code 4)부터 학습 HTML/JavaScript/표현 자료는 Play 설치 파일과 별도로 갱신합니다. 게시된 내부 테스트 앱은 **0.6.1/code 16, 출시 11**이며 **2026-11-07 18:15 KST에 내부 테스터 제공 상태를 확인**했습니다. 설치 파일에 포함된 화면은 **v4.6.0**입니다. 네 가지 연습을 유지합니다. 공개 프로덕션 출시와 실제 휴대폰 검증은 완료되지 않았습니다.

별도 화면 수정 **v4.6.1**은 전체 정답 30/15 XP, 표현만 맞힌 답 15/10 XP와 부분 정답 숙련도 변화 0을 적용합니다. 소스 `a5cac183aad2584ca1983982af92f5599d9f676f`, 최소 앱 코드 16, Node **182/182** 통과입니다. **Actions 42359338013 성공, 라이브 descriptor와 주요 파일 8개의 해시 일치를 2026-11-07 18:26 KST에 확인**했습니다. v4.6.0 포함 설치 파일의 Node 173개·JVM 65개와 구분하며, 기존 AAB/APK 해시는 바꾸지 않았습니다. [출시·별도 웹 수정 기록](../docs/release-0.6.1.md)에 각 결과와 증거를 보관합니다. 20개 후보 답안은 활성화하지 않았고 이번 수정에 학습 데이터셋 추가는 없습니다.

## 사용자에게 반영되는 시점

- 앱을 새로 실행할 때 최신 배포를 확인하고 완전히 내려받은 뒤 엽니다. 확인/다운로드는 약 20초의 제한이 있으며 네트워크 읽기 제한 때문에 수 초 더 걸릴 수 있습니다.
- 1분 이상 다른 앱에 있다가 돌아오면 다시 확인합니다. 홈 화면일 때만 적용하고 진행 중인 학습은 바꾸지 않습니다.
- 홈 하단의 ‘업데이트 확인’으로 즉시 확인할 수 있습니다. 대화·듣기·단어 학습 등에서는 먼저 홈으로 돌아갑니다.
- 오프라인/배포 오류/검증 실패 시 마지막 정상 배포를 사용하고, 캐시가 없으면 설치 파일의 화면을 사용합니다. 원래 HTTPS 앱 출처를 유지하므로 학습 localStorage와 로그인 정보는 유지됩니다.

## 수정 → 배포

현재 통합 작업 브랜치 `codex/android-chatgpt-voice` 또는 통합 후 `main`에 학습 파일을 커밋하고 push하면 `Publish Android learning screen` GitHub Actions가 실행됩니다. 로컬 수정만으로는 반영되지 않습니다. 검증 후 `android-web-live` 브랜치의 배포 설명서를 갱신합니다. 네이티브 코드만 바꿀 때는 학습 배포가 실행되지 않습니다.

설명서는 원본의 불변 커밋 SHA와 파일별 크기/SHA-256을 담습니다. 앱은 고정된 저장소의 HTTPS 주소만 사용하고 리다이렉트를 거부합니다. 모든 파일이 일치할 때만 원자적으로 활성화합니다. 배포 설명서의 해시는 GitHub 계정과 TLS에 대한 신뢰에 기반하며 별도의 개발자 서명은 아닙니다. GitHub 쓰기 권한은 실행 가능한 앱 화면의 배포 권한입니다.

자동 배포 목록은 `scripts/android-web-release.cjs`에서 관리합니다. 새 CSS/JS/이미지 파일을 추가하면 여기에 포함해야 합니다. 파일을 임의 외부 URL에서 로드하거나 네이티브 토큰을 JS에 전달하지 않습니다. 배포 파일은 80개/합계 24MB/파일 8MB 이내입니다. 새 앱 시작 시 이전 캐시는 하나만 남깁니다.

## Play 업데이트가 필요한 변경

로그인/마이크/Android 권한/새 네이티브 메시지 동작/서명/target API는 AAB 재배포가 필요합니다. 이때 `android/web-release-config.json`의 `minimumNativeVersion` 또는 `bridgeVersion`을 함께 조정합니다. 구버전 앱은 호환되지 않는 화면을 적용하지 않고 이전 화면을 유지합니다. 웹 배포에도 Play 정책과 데이터 공개 의무가 적용되며 심사 통과를 보장하지 않습니다.

v4.6.0과 v4.6.1은 실제 발화 시작 시점과 권한 창을 열지 않는 백그라운드 연결 준비를 사용하므로 **minimumNativeVersion 16**입니다. 0.6.0/code 15에 웹 파일만 적용해 새 시간 측정이나 사전 준비가 지원된다고 표시하지 않습니다. 두 `WebUpdater` 생성자도 실제 앱 코드 16으로 맞추고, 네이티브 패키지와 웹 descriptor의 기대값을 함께 검증합니다. 기존 앱은 호환되는 이전 화면과 기록을 유지합니다.

문제가 있는 학습 배포는 GitHub Actions에서 이전 정상 소스 커밋을 다시 배포하거나 정상 상태를 복원하여 push합니다. 되돌릴 때도 학습 기록은 삭제하지 않습니다.

검증: Node 네 가지 연습·음성 연결·배포 설명서 검사, JVM 크기/해시/경로/호환성/부분 다운로드 검사, release lint/AAB 빌드. 실제 폰에서 네트워크 차단·복귀·다운로드 중 종료·기록 유지·연습 중 미갱신은 추가 검증이 필요합니다.
