# 3초영어 Android

0.5.0 / versionCode 5. 홈은 여행 표현, 골라서 연습, 자주 틀리는 문장, AI 실전회화 네 가지입니다. Android 8 이상 / target API 36.

AI 실전회화에서 ChatGPT 연결 설정을 열어 각자의 계정으로 로그인하고 모델 선택·연결 테스트를 완료합니다. 상대의 첫 응답을 받은 뒤 같은 대화 화면에서 음성으로 대화를 이어갈 수 있습니다. 음성 입력과 읽기는 Android 기능이며 ChatGPT 앱의 음성모드를 내장한 것은 아닙니다.

별도 반복 대화 메뉴·학습 기록 파일 가져오기/내보내기·별도 연결 홈 메뉴는 제거했습니다. 원래 기기에 저장된 여행 표현·선택·오답은 유지합니다. 웹과 Android는 서로 다른 저장 공간을 사용합니다. 홈에는 기존 디자인의 루틴·성장·자동 난이도·랭킹·프로필·동기화·튜토리얼이 복원되었습니다. 닉네임 동기화를 연결하면 웹/Android 저장 공간의 학습 기록을 합칠 수 있습니다. 연결 토큰과 대화 내용은 동기화하지 않으며 기존 서버 기록을 일괄 삭제하지는 않습니다.

로그인 정보는 네이티브 Keystore에 암호화 저장하고 JavaScript에 전달하지 않습니다. AI 대화는 기존 원격 요청 계약을 각자의 ChatGPT 연결로 보내며 연결 실패 시 API 키 결제나 다른 프록시로 자동 전환하지 않습니다. 일반 웹의 AI 요청은 기존 Cloudflare/Claude 경로를 사용합니다.

학습 화면은 [자동 배포](WEB-UPDATES.md)로 갱신하고, Android 로그인·마이크·권한 변경은 Play AAB 업데이트가 필요합니다. 설치 파일에는 같은 학습 화면을 포함하여 오프라인 배포 확인 실패에도 열 수 있습니다.

검증: Node 연습/음성 연결/배포 테스트, JVM OAuth/응답/명령/배포 무결성 테스트, release lint와 AAB 빌드. 실제 계정별 OAuth와 휴대폰 마이크·음성 대화 검증은 남았습니다.

Play 업로드는 사용자의 요청으로 중단했습니다. APK 직접 설치나 보안 해제를 안내하지 않습니다. 개인정보 안내는 검토용이고 운영자 정보와 문의 방법이 필요합니다. [Play 제출 준비](PLAY-RELEASE.md)를 참고하세요.
