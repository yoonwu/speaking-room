## 이전 버전 0.5.8의 구현 기록

아래는 당시 경로와 검증 이력입니다. 새 후보의 마이크 흐름·점수·검증 완료 여부를 뜻하지 않습니다.

0.5.8 / versionCode 13. 홈은 기본표현, 골라서 연습, 자주 틀리는 문장, AI 실전회화 네 가지입니다. Android 8 이상 / target API 36.

0.5.8은 네이티브 마이크의 초기 주변 소음 보정을 개선합니다. 시작 직후의 무음 버퍼를 제외하고, 바로 말하기 시작한 유성음과 큰 자음 소리가 소음 기준에 섞여 답변을 자르지 않도록 보호합니다. 인식 경로는 변경하지 않습니다. Android 단위 테스트32개와 실제 TTS WAV를 사용한 깨끗한 음성/합성 소음 조건6개를 통과했습니다. 실기기 전체 흐름 확인은 내부 테스터 검증 단계입니다.

학습 화면 v4.4.8(2026-11-05)부터 0.5.7 이상 앱의 반복학습은 기존 `recordPractice` 기능으로 WAV를 녹음한 뒤 운영 음성 서버에서 인식합니다. 아래의 기기 인식기 녹음 입력 경로에 의존하지 않습니다. 기기 무음 감지와 별도의 최대 녹음 시간을 함께 적용하며 ChatGPT 연결은 필요하지 않습니다. 앱을 다시 설치할 필요 없이 학습 화면 업데이트로 적용됩니다. [실제 음성 데이터·서버 검증과 미확인 범위](../docs/speech-input-verification.md)를 참고하세요.

AI 실전회화에서 ChatGPT 연결 설정을 열어 각자의 계정으로 로그인합니다. 브라우저의 ‘3초영어로 돌아가기’ 버튼은 앱만 열고, OAuth 결과는 검증된 loopback 콜백으로만 받습니다. 앱이 화면에 돌아온 뒤 토큰 교환을 진행해 백그라운드 모바일 데이터 제한을 피하며, 모델과 대화 연결을 자동으로 확인하고 저장합니다. DNS 실패만 최대 두 번 재시도하고, 이미 서버에서 처리됐을 수 있는 토큰 교환·응답의 타임아웃은 자동 재전송하지 않습니다.

상대의 첫 응답을 받은 뒤 같은 대화 화면에서 음성으로 대화를 이어갈 수 있습니다. 음성 입력과 읽기는 Android 기능이며 ChatGPT 앱의 음성모드를 내장한 것은 아닙니다.

기본표현 정답 화면에 ‘내 목소리 듣기’를 복원했습니다. 웹은 MediaRecorder가 만든 같은 답변의 녹음을 재생하며, 기기 음성 인식이 먼저 끝나도 녹음을 유지합니다. Android 13 이상은 마이크를 한 번 녹음한 뒤 해제하고, 같은 PCM을 [공식 녹음 입력 API](https://developer.android.com/reference/android/speech/RecognizerIntent#EXTRA_AUDIO_SOURCE)로 음성 인식기에 전달합니다. 사용 중인 인식 서비스가 이 API를 지원해야 합니다. Android 8~12는 기존 음성 인식을 유지하며, 결과 화면에서 별도로 한 번 녹음해 비교할 수 있습니다. 최대 25초의 녹음은 메모리에서만 유지하고 다음 문장·홈 이동 시 해제하며 동기화하지 않습니다. 새 기본표현 튜토리얼은 처음 답안을 보고 익힌 뒤 같은 표현을 답안 없이 꺼내는 흐름을 두 장면으로 보여줍니다.

별도 반복 대화 메뉴·학습 기록 파일 가져오기/내보내기·별도 연결 홈 메뉴는 제거했습니다. 원래 기기에 저장된 기본표현·선택·오답은 유지합니다. 웹과 Android는 서로 다른 저장 공간을 사용합니다. 홈에는 기존 디자인의 루틴·성장·자동 난이도·랭킹·프로필·동기화·튜토리얼이 복원되었습니다. 닉네임 동기화를 연결하면 웹/Android 저장 공간의 학습 기록을 합칠 수 있습니다. 연결 토큰과 대화 내용은 동기화하지 않으며 기존 서버 기록을 일괄 삭제하지는 않습니다.

로그인 정보는 네이티브 Keystore에 암호화 저장하고 JavaScript에 전달하지 않습니다. AI 대화는 기존 원격 요청 계약을 각자의 ChatGPT 연결로 보내며 연결 실패 시 API 키 결제나 다른 프록시로 자동 전환하지 않습니다. 일반 웹의 AI 요청은 기존 Cloudflare/Claude 경로를 사용합니다.

학습 화면은 [자동 배포](WEB-UPDATES.md)로 갱신하고, Android 로그인·마이크·권한 변경은 Play AAB 업데이트가 필요합니다. 설치 파일에는 같은 학습 화면을 포함하여 오프라인 배포 확인 실패에도 열 수 있습니다.

검증: Node 연습/음성 연결/배포 테스트, JVM OAuth/응답/명령/배포 무결성 테스트, release lint와 AAB 빌드. 실제 계정별 OAuth와 휴대폰 마이크·음성 대화 검증은 남았습니다.

Play 내부 테스트로 업데이트를 배포합니다. APK 직접 설치나 보안 해제를 안내하지 않습니다. 일반 공개 출시는 스토어 등록정보·앱 콘텐츠 설정·비공개 테스트 요건을 완료해야 합니다. [Play 제출 준비](PLAY-RELEASE.md)를 참고하세요.
